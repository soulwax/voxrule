# voxrule

Pure Dart RPG & tactical combat rules toolkit: stackable status effects with tag immunities/dispels, periodic DoT/HoT ticks, damage shields, multi-charge cooldowns + GCD, ATB/initiative turn scheduling, and deterministic damage mitigation pipelines.
